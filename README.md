# falkordb-cognee-adapter

FalkorDB hybrid (graph + vector) adapter scaffold for Cognee 1.0.3.

## Status

v0.1.x — porting the upstream 0.5.6 adapter to Cognee 1.0.3. Slice 0 (DX scaffold) complete. Slice 1+ in progress.

## Quickstart

```bash
make install && make test
```

## Reference

The original 0.5.6 adapter source is preserved at `references/upstream-0.5.6/` for porting guidance only — DO NOT IMPORT FROM IT.

Upstream project: <https://github.com/topoteretes/cognee-community>
